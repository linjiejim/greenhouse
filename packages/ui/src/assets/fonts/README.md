# Nunito

Nunito is bundled locally for the Greenhouse interface. Normal and italic
variable fonts support weights 200–1000; Chinese falls back to the system CJK
font. Monospace content keeps its own font.

Source: https://github.com/google/fonts/tree/main/ofl/nunito
