# Nunito

Nunito is bundled locally for the Greenhouse web interface (`../../styles/fonts.css`): normal
and italic variable WOFF2, weights 200–1000, no external font request at runtime. Chinese falls
back to the system CJK font (PingFang SC, Microsoft YaHei, Noto Sans SC); code keeps its own
monospace stack. The mobile app bundles its own named instances (apps/mobile/assets/fonts).

Source: https://github.com/google/fonts/tree/main/ofl/nunito (upstream commit
`8c6a9bb9732545b9ed53f29ec5e1ab0ff53c4e6f` of https://github.com/googlefonts/nunito), the same
files as main's packages/ui/src/assets/fonts.
