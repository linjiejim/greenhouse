用 `TEST_DATABASE_URL=postgresql://…/greenhouse_v2_test pnpm eval` 回放。脚本模型固定实际模型输出，检查当前提示组装、工具集合和定义、action 参数校验、审批门；不判断真实模型答案质量。工具定义或可用性有意改变后，应审阅差异并从合成真实对话重新导出，不能为让测试通过盲目改期望。
