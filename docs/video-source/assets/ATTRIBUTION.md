# Asset sources

- Product captures: `docs/assets/screens/`, from the repository's fictional example workspace.
  See the Web and native capture manifests there.
- Brand artwork: canonical Greenhouse Haven artwork from `logos/`.
- Nunito: bundled project font from `packages/ui/src/assets/fonts/`.
- Noto Sans SC: bundled report font from `apps/api/assets/fonts/`; license in `fonts/OFL.txt`.
- GSAP 3.15.0: local vendor copy distributed with HyperFrames 0.8.201. Its copyright and
  license link remain in the file header; see <https://gsap.com/standard-license/>.
- Fade-through component: official HyperFrames registry, pinned by `hyperframes.lock.json`.
  The film adapts its opacity easing to overlapping screenshot crossfades.
- Narration: macOS Tingting, synthesized locally from the text in `narration.json`.

No third-party music, stock footage, voice clone or AI-generated product image is used.
