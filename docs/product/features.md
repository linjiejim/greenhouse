# Greenhouse v2 功能清单

更新 2026-10-14 · 配套 [PRD](prd.md)、[常驻 Agent](always-on.md)。这是 v2 唯一的功能台账：每个功能一行、一个 ID，并随实现更新状态。

v2 决定
- `保留`：沿用。
- `改造`：保留，但交互或实现要改。
- `新增`。
- `合并`：并入另一功能，备注写去处。
- `删除`：不迁移，必要时备注替代方案。

状态
- `规划`
- `进行中`
- `已实现`：代码合并且验证通过，备注写 PR。
- `待删`
- `已删`：代码与文档都已清理，备注写 PR。

端：W = Web，I = iOS，A = Android，E = 浏览器扩展，D = 桌面 App。原型（`apps/design`）里定稿不算实现，备注写「原型已定」。

维护规则：
- 改行为时在同一个 PR 里更新这一行。
- 新功能先加一行，回答它属于[哪个对象](prd.md#4-对象模型)，以及为什么不能复用现有功能。
- 删除一个功能，要同步删除它的导航、路由、工具、i18n、测试、种子数据、文档和截图。
