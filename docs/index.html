Open source under MIT. Run the workspace on your own infrastructure, then connect your team and their agents.

Get Greenhouse ↗ Deployment guide
Docker Compose 
git clone https://github.com/linjiejim/greenhouse.git
cd greenhouse
cp .env.example .env
./scripts/gen-secrets.sh
# Set LLM_BASE_URL, LLM_API_KEY, LLM_MODEL in .env
docker compose up -d --build
docker compose exec api pnpm admin:create

For production, use a tagged release. Configure a model before starting.
