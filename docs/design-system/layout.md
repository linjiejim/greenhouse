# 布局

有哪些入口见 PRD §6；本文规定它们怎么摆。

## 桌面应用壳（≥ 1024px）

- 四栏：全局栏 64，模块目录 256（可拖到 220–320，可收起），工作区，抽屉（按需，盖在工作区上方，不挤压内容）。
- 全局栏：顶部 Haven 标志，点它回到主线；中间对话、知识库、表格、应用、更多；底部运行、通知、头像。没有权限或没启用的模块不显示入口。模块按钮有右键菜单，放这个模块的新建类操作。
- 模块目录：标题行 56（模块名、搜索、收起），满宽主操作，列表，底部低频入口（已归档）。搜索在标题行原地展开，列表不跳动。收起后页头左侧出现「展开目录」。
- 工作区：一个页头加一个纵向滚动区。一个视图最多两个纵向滚动区：模块目录和工作区。

## 目录行

- 行高 32，左边图标或头像 20，右边最多一个信号：需要你的数字 > 静音 > 运行中 > 未读。
- 只显示名字，不显示最新消息。
- 当前项用 selection 底加粗；右键菜单打开时，这一行保持悬停底色。
- 「›」只表示能展开；层级用 16 的缩进。
- 对话目录的 Agent 区在最上方，没有标题，不能折叠。主 Agent 一行高 52、头像 36、字号 titleSm；其他 Agent 行高 32、头像 20。下面才是带标题的「房间」「会话」分区。

## 页头与内容宽度

- 页头高 56：标题、可选的「?」、状态徽标、弹性空白、至多一个主操作、「⋯」。不写描述句。
- 页面顺序：页头、可选的 Banner、Tabs、工具栏、内容。
- 内容最大宽度：阅读 760 居中（对话、文档）；表单 720 左对齐（设置、管理、资料）；列表 1200；画布全宽（表格网格、时间线、搭建器、电脑）。
- 对话页的页头只放对象身份（头像、名字、一行状态）、电脑、信息、「⋯」。

## 抽屉、对话框与 Sheet

- 抽屉：窗口宽度的 40%，最小 480，最大 880；电脑画面和网页预览用宽抽屉，60%，最大 1200。占满高度，头部最小 56（长标题允许换行）和操作区固定，只有正文滚动。一次只开一个；关联对象在同一个抽屉里切换，并提供返回。
- 对话框：宽 440（宽版 640），只用于短小的决定和确认。
- Sheet（手机）：从底部弹出，顶部圆角 24，有拖动手柄，同时有关闭按钮；最高 92dvh；下拉约 90px 关闭；有未保存内容时先询问。
- 抽屉挂到整个应用壳的浮层边界，遮罩覆盖工作区、目录与全局栏；不要挂在带定位的页面或另一个抽屉正文中。遮罩只压暗，不模糊。关闭后，列表的筛选、滚动位置和选中项保持原样。

## 响应式

- ≥ 1280：同桌面。
- 1024–1279：同桌面；宽抽屉退回普通抽屉。
- 768–1023：全局栏常驻，模块目录以浮层打开；抽屉最多占 90%。
- < 768：与原生 App 一致。页头左边打开抽屉，右边是通知；抽屉里依次是 Agent 区、房间、会话，底部是模块栏（对话、知识库、表格、应用、更多）。详情用 Sheet；长表单、编辑器、电脑全屏。
- 手机上触摸目标至少 44，输入框字号至少 16；悬停才出现的东西都能通过点按、长按或「⋯」拿到；宽表格只在自己的区域里横向滚动。

## 桌面 App

- 页头空白处可以拖动窗口；macOS 上全局栏顶部给交通灯让出 28。
- 快捷启动和划词条是无边框小窗口，只有输入框和结果。

- 抽屉的共用结构：标题与关闭、单一滚动正文、固定底部操作。Web 表单主操作在页脚右侧；消息卡片操作在左侧，主操作在前。原生的 FormChrome 和 SheetActions 把操作交给 screenLayout 的 SheetFrame，主操作全宽，避开键盘与底部安全区；半高 sheet 的渐隐仅覆盖正文。详情不重复标题，不在表单外再套装饰卡片。关闭、返回与手势仍经过原来的草稿保护。
