# 交互动效（#70，U1）

动效解释位置、反馈与状态，不能延迟提交或隐藏重要信息。Web 只用 haven.ts 的 fast 140ms、base 200ms、slow 240ms、exit 180ms 与 standard／enter／exit 曲线。系统开启减少动态效果时，取消位移、脉冲和过渡，保留即时状态。原生 sheet、菜单和分段使用系统动效；新增 Reanimated 效果显式遵守 ReduceMotion.System。

| 交互 | 实现与目的 |
| --- | --- |
| 新回复出现 | Web 正在流式写入的新回复用 200ms 淡入加 4px 上移；历史内容不逐条重播。原生新回复与流式段落淡入，降低突变感。 |
| 正在思考／流式尾部 | Web 轻指示与细小尾标，原生仅文字脉冲，不增加头像行。减少动态效果时静止。 |
| 卡片决定与展开 | 边线／底色用 200ms 过渡；ChatCard 测量显示高度，只在 attention、展开或收起为摘要的状态变化时插值到新高度。决定完成后的详情默认收起，选中的答案仍保留；被取代／撤回时保留同一容器，200ms 收为中性单行，替代链接仍可用。原生卡片用 LinearTransition，状态仍由请求模型提供。 |
| 行内选项 | 140ms 轻微回弹到原尺寸，立即变为所选态；等待中全组禁用。失败恢复可选。 |
| 抽屉／sheet | Web 240ms 进入、180ms 退出，固定页脚不参与正文滚动；原生沿用系统 presentation。 |
| 菜单／浮层 | 沿用 kit 的快速淡入和焦点进入／返回，选择动作即时执行。原生沿用系统菜单。 |
| Toast | Web 沿用轻微上浮，原生快速淡入／淡出；文字可换行，减少动态效果时没有位移。 |
| 目录收展 | 200ms 宽度和内边距变化，隐藏后 inert，不能进入键盘焦点。浮动目录仍以遮罩打开。 |
| 回执列表 | 新回执以 200ms 淡入；撤销后保留事实与结果，卡片高度变化使用相同规则。没有人为增加删除回执的交互。通知列表由 U3 负责。 |
| 分段／章节页签 | 200ms 指示块／下划线滑动，同步测量字号与可用宽度；不改变焦点或原有箭头键顺序。可增删的表格对象页签保留独立选中线。 |
| 骨架转正文 | 新挂载的工作区／抽屉正文轻微淡入，骨架本身静止，不使用闪烁或扫光。 |
| 主题切换 | 偏好在 head 中恢复，服务端成员偏好在布局阶段原子应用，避免先显示另一个主题。颜色即时切换，不跨两个主题做漫长渐变。 |

不要为了动效保留已不可访问的私有内容。关闭与删除仍遵守原有权限、草稿保护及请求生命周期。通知生命周期和列表动效由 U3 在自己的改动中验证。

## 植物头像（V2，C1）

植物头像的状态动效使用共享 V2 控制器，是工作状态的专用节奏，不套用普通界面的 120–240 ms。只移动已有图层并改变脸部路径；物种轮廓、配色、细节等级、光学适配和静态 SVG 不变。每个实例只有一个当前状态与版本，临界阻尼弹簧从当前位置和速度改向；重复状态不重播，没有延迟完成事件恢复旧状态。

视线先到，身体与枝叶随后；睡醒先睁眼再开口。hello、done、error 是有限手势，结束后安定；idle 只有长周期中的一次小呼吸和偶尔眨眼，大部分时间静止。工具运行或等待首段正文为 thinking，流式正文为 speaking，待成员决定为 waiting，观察到成功完成后短暂 done，最终失败为 error；已有休眠／安静展示沿用 sleep，首次打开与问候用 hello。历史成功回复不重播完成。

一对一回复不增加头像行，状态放在页头，正文保留轻思考指示；房间放在原有作者行，Agent 页面使用现有头像。目录和普通列表明确关闭动画，仍显示状态表情；实时状态、问候与大头像才进入动画预算。Web 所有实例共享一个帧循环，离屏或页面隐藏暂停，恢复时不追赶后台时间。原生使用同一份受逐字校验的控制器，在 Reanimated UI 线程更新；进入后台停钟。减少动态效果时保留静态表情，只允许淡入淡出。

冻结对照面保留在 examples/plant-motion-review；V1 原件不变，V2 直接复用产品控制器。
