# 模式

## 列表与详情

- 点开对象：桌面在右侧抽屉，手机在底部 Sheet。记录、Agent、运行、通知来源、连接、服务、成员、技能版本都这样。
- 详情的结构：头部（名字、状态、在新页面打开、「⋯」、关闭），正文（字段、关联、评论、活动），操作区。
- 打开详情会改 URL（例如 ?record=…）；浏览器后退先关闭详情。
- 就地编辑：点「编辑」后，同一个抽屉切到编辑态，操作区变成「取消 / 保存」。保存失败保留草稿，错误写在字段旁；有改动时关闭，先问保留还是放弃。不在抽屉里再弹居中的编辑框。
- 文档编辑器、时间线、搭建器、电脑画面用专用的全屏工作区，抽屉里只放「打开」。
- 关联对象在同一个抽屉里切换，并提供「‹ 返回」；不叠第二层抽屉。
- 加载中用同尺寸骨架；保存中不能重复提交；已删除或无权限时说明原因，不露出旧内容，仍然能关闭。

## 保存

- 偏好和开关即时保存，旁边短暂显示「已保存」；失败时恢复原值并说明。
- 一组配置显式保存：区块底部固定操作条，依次显示「有未保存的更改」「保存中」「已保存」或「保存失败」。
- 同一个区块不混用即时保存和显式保存；保存按钮只有一个。
- 机密只写，保存后清空输入框。
- 区块：标题加可选的「?」；字段间距 16，区块间距 32，用细线分隔，不套卡片。两个短字段可以并排，长文本和机密独占一行，手机上一律单列。
- 有未保存的修改时离开页面，先询问。

## 确认与撤销

- 能撤销的不确认，用 Toast 给「撤销」：归档、移动、标为已读、从目录删除会话。
- 不可逆的才确认，写清对象和后果；删除整个表格、应用或成员时要输入名称。
- Agent 的写入在对话里的「需要你」卡片确认。

## 右键菜单

- 目录行的菜单就是这个对象页头「⋯」里的操作：
  - 会话：置顶或取消置顶、重命名、复制链接、导出 Markdown、删除。
  - Agent：新会话、查看资料、电脑、静音通知、标为已读、归档（主 Agent 不能归档）。
  - 房间：复制链接、静音通知、标为已读、重命名、离开房间。
  - 文件夹、文档、表格、数据表、视图、应用：各自的新建、重命名、复制、移动、删除。
- 全局栏按钮的菜单是这个模块的新建类操作。对话：新会话、新房间、新建 Agent、全部标为已读。知识库：新文档、上传文件、新文件夹。通知：全部标为已读、通知设置。
- 设置、管理这类分区列表没有右键菜单。
- 危险操作放最后，用分隔线隔开；能撤销的直接执行，再给 Toast。

## 数据视图

- 层级：表格 → 数据表 → 视图。Tabs 切换视图，下面的工具栏依次是搜索、筛选、排序、分组、字段、「⋯」。
- 点复选框是选择（Shift 选区间，出现批量操作条）；点单元格是编辑（Enter 保存，Esc 取消，Tab 下一格）；点标题或行尾「打开」是打开详情。一次点击只做一件事。
- 生效的筛选显示为可清除的标签；改筛选时回到第一页；总数在页脚，由服务端计算。
- 「本来就空」「筛选后没有」「没有权限」「查询失败」分开显示。
- 保存时发现别人改过，提示「重新载入 / 覆盖」，不静默覆盖。批量操作部分失败时，说明成功和失败各几条，保留失败的选择。
- 手机默认显示摘要列表，可以切到完整网格；记录用 Sheet 打开。
- 对话里的表格是只读结果，可以导出 CSV 或跳到原表。

## 空、载入与失败

- 首次为空：一句话加一个操作（「还没有表格」加「新建表格」）。
- 没有结果：「没有匹配的…」加「清除筛选」。
- 失败：出了什么错、保留了什么，加「重试」和可复制的错误号。
- 没有权限：「你没有访问权限」，并说找谁。
- 能力没配置：入口直接不出现；只在管理员的「?」里写配置路径。

## 帮助与渐进展开

- 页面上只放完成任务必需的信息，其余放进「?」。
- 低频设置收进默认折叠的「高级」，标题右边写当前值的摘要。
- 长列表先显示最近的，较早的收起。
- 不写教学句。

## 搜索与命令

- ⌘K：全局搜索（按类型分组）加命令（新建…、打开…）；键盘完全可用；最近访问排在前面；没有结果时可以「问 Agent」。
- 模块目录里的搜索只筛选当前列表。

## 通知

- 只有一个角标，在通知铃上：需要你的数量；没有需要你时显示未读小点。
- 通知中心分「需要你」（按截止排序，可以就地处理）和「全部」。点一条回到来源对象和对应状态；来源失效时说明发生了什么变化。

## 服务配置

- 「管理 → 服务」是列表加抽屉。每个能力一行：名称、「?」、当前实例、来源、状态点。抽屉里是有序的实例（顺序就是回退顺序）、添加实例（先选预设）、测试连接、默认项、是否允许个人 Key。
- 来自环境变量的实例只读，并标明来源。Key 一律用 SecretField；改了地址必须重填 Key。

## 登录

- 只有标志、「Greenhouse」、邮箱、密码和一个高 44 的登录按钮；配置了飞书时，分隔线下多一个同样大小的「飞书登录」。
- 错误写在密码下方，重新输入后消失。不放注册入口、说明文字和「?」。
