# 对话

功能范围见 PRD §7.1–7.3。

## 目录

- 最上方是 Agent 区，没有标题，不能折叠。主 Agent（默认叫 Greeny）一行高 52、头像 36；其他 Agent 一行高 32、头像 20。Agent 多时只列最近的几个，末尾加一行「全部 Agents」。
- 然后是「房间」（标题旁有「+」）和「会话」（置顶、今天、可展开的「更早」）。
- 每行只显示名字，不显示最新消息；右侧一个信号：需要你的数字 > 静音 > 运行中 > 未读。
- 后台运行不在目录里列出，只在 Agent 行上显示运行中；完整列表在「运行」。
- 每一行都有右键菜单，内容见 patterns.md。

## 对话页

- 页头：头像（房间显示成员头像叠放）、名字、一行状态（「主线」「运行中 · 生成周报」）；右边是电脑（有电脑时）、信息、「⋯」。「⋯」和这一行的右键菜单是同一份操作。
- 消息列居中，最大宽 760。用户消息是 fill 底的轻气泡，靠右；Agent 回复不加气泡，用 bodyLg。
- 单人对话（主线、Agent 对话、单个 Agent 的会话）的 Agent 回复不重复头像和名字。房间的作者头像、名字、时间占上方一行，正文在下方用满阅读宽度；同一作者连续发言只显示一次。成员自己的消息保持气泡与时间。思考只用轻微指示，不再加头像行。
- 长对话顶部显示「已摘要较早的内容 · 查看摘要」，不截断原文。
- 只读对话：输入框的位置显示原因和唯一能做的事（恢复、新建会话）。

## 回复的顺序

结论，结果卡片，来源，过程卡片。块里的按钮只会发出一条用户看得到的消息，不直接执行操作。生成中的块用同尺寸占位，不露出原始 JSON 或 HTML。

## 回复卡片

所有卡片共用一个布局（原型里的 ChatCard）：
- 外框：surface 底，1px line，圆角 lg；与正文同宽，卡片之间间距 12。
- 标题行高 44：图标 16（secondary 色），标题（加粗），「· 元信息」（secondary 色），弹性空白，状态标签固定在最右侧。
- 正文：左右和底部内边距 12，块之间间距 12。
- 底部：结果卡片的操作在左下（打开、下载、导出、网页预览，都是轻按钮）；决定卡片的按钮也在左下，主按钮在前，左边可以有一句范围说明（「仅批准这一次」）。处理之后，底部换成一句结果。

结果卡片：记录（每行一条：标题、负责人与截止日期、状态、›）、表格摘录（打开表格、导出 CSV）、图表、文件产物、图片、视频（生成中时标签是「生成中」，可以去运行里看进度）、音频。没有状态时不放标签。

过程卡片：一次工具调用折叠成一行，用箭头开头代替图标，点开看明细和失败原因；多步运行列出每一步和时间。标签用运行的状态词，完成态用中性色，只有运行中、失败、需要你着色。失败的过程卡片默认展开，给「重试」。

决定卡片（需要你）：边框带一点 warning 色，图标用 warning 色。待处理时标签是「需要你」，处理后是已批准、已拒绝、已过期或已完成，按钮消失。五种：
- 批准：动作、对象、变化预览、本次授权的范围。
- 登录：网站与原因；登录信息来自密码库，Agent 看不到明文。
- 接管：原因和电脑缩略画面；完成后交还。
- 提问：ask_user 仅有一个 choice 字段且有 1–6 个选项时，选项直接显示在消息里，点一次即回答；发送中显示选择并禁用所有选项，失败恢复，成功保留所选。文字输入、多字段和更多选项打开抽屉／原生 sheet。继续使用原来的 answers 键值，不添加展示用 API 标记。
- 提议：新建 Agent、修改指令（显示差异）、开始后台运行（显示简报）。
确认之前不会执行任何操作；会过期的卡片显示剩余时间。

来源是一行可点的来源标签，点开在侧栏预览。代码块不算卡片：浅底，顶部一行语言名和复制按钮。

## 输入框

- 最大宽 760，圆角 20，surface 底加线，聚焦时边框变 focus。
- 文本框随内容增高，最多到视口的 40%。Enter 发送，Shift Enter 换行；输入法组字时不发送。
- 工具行：左边附件、@、/，右边语音输入和发送。
- @：房间里列出成员和 Agent；新会话里用来切换 Agent。/：只列当前可用的技能，带变量时光标进入第一个字段。
- 附件显示为药丸，可以单独移除；全部上传完之前不能发送。
- 语音输入：录音时显示波形和计时，Esc 取消；识别结果填进输入框，从不自动发送。没有 STT 服务、浏览器也不支持时，不显示麦克风。
- 发送和停止互斥；生成中继续发送会排队，并提示「已排队」。
- 模型选择只在会话里、而且工作区有多个模型时出现，放在「⋯」里。

## 消息操作

- 每条消息只提供一个「⋯」操作菜单；桌面悬停或键盘聚焦时出现，触摸和原生常显小入口。复制、反馈、朗读、引用、从这里新开会话及重新生成都在菜单中。编辑和重新生成继续受现有资格限制；箭头键进入菜单，Esc 回到触发按钮。
- 朗读用 TTS 服务，没有时用浏览器朗读；只读正文，不读代码和表格；朗读中按钮变成停止。

## 侧栏

与详情抽屉同宽，一次只开一项：信息（成员、摘要、共享笔记）、电脑（画面、终端、文件、进程；观看和接管是同一画面的两种状态）、预览（记录、文档、文件、网页、来源）。窄屏用 Sheet，电脑全屏。

## 页面助手

在任何页面按 ⌘J，从右侧打开同一个对话组件，并带上页面上下文（显示为可以移除的标签）；保存为会话。

## 回复排版

聊天回复里的粗体用 medium（500），标题使用正文大小加 medium；行内代码只有等宽文字，没有填充药丸。列表保持紧凑。代码块、表格、链接保留专用样式。知识文档的标题层级与安全 Markdown 规则不受影响。审批的受限预览继续禁止链接、图片和控件。
